# Task-Manager
A console-based task management application built in Java. The project allows users to create, view, update, and remove tasks. It uses object-oriented programming, ArrayList, loops, input validation, and unique task IDs.
A console-based task management application built in Java. The project allows users to create, view, update, and remove tasks. It uses object-oriented programming, ArrayList, loops, input validation, and unique task IDs. It saves all tasks into a txt file so that when  you run the program again they are still there.

Current Features

Create tasks
View current tasks
Update completion status
Remove tasks
Unique task IDs
Input validation
File/IO 

Future Improvements


Task priorities
Due dates
Better error handling
